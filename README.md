# WebTech Quiz App — MERN Stack

## Setup Instructions

### 1. Backend
```bash
cd backend
npm install
# Edit .env — add your MongoDB Atlas URI and JWT secret
npm run seed    # Seeds 60 questions into Atlas
npm run dev     # Starts backend on http://localhost:5000
```

### 2. Frontend
```bash
cd frontend
npm install
npm run dev     # Starts Vite on http://localhost:5173
```

### Subjects
- Machine Learning (ML) — 20 questions
- MERN Stack (MERN) — 20 questions
- C++ Programming (CPP) — 20 questions
